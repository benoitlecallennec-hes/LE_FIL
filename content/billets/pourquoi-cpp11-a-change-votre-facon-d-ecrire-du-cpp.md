D'après sa description, cette courte vidéo de CppCon présente C++11 comme un tournant majeur pour le développement logiciel. Cette version aurait fait passer le langage de ses racines héritées du C à une ère moderne.

Elle passe en revue les apports qui ont transformé la programmation en C++ : la déduction de type avec `auto`, pour un code plus lisible ; les pointeurs intelligents, qui épargnent les écueils de la gestion manuelle de la mémoire ; la sémantique de déplacement, qui améliore nettement les performances ; les expressions lambda, qui ouvrent la voie aux motifs de programmation fonctionnelle ; et les boucles `for` sur intervalle, entre autres.

La vidéo s'adresse aussi bien aux développeurs C++ confirmés qu'aux débutants. Elle soutient que comprendre l'apport de C++11 est indispensable pour écrire du C++ moderne efficace et maintenable.
